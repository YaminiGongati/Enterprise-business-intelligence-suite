                             # Enterprise Business Intelligence Suite

A SQL Server and Power BI analytics project developed as part of the Nexvia Technologies Data Analytics Internship Project.

## Project Overview

This project analyzes sales-related data from the AdventureWorksDW2025 sample data warehouse and presents business metrics through an interactive Power BI dashboard.

## Objectives

- Analyze sales data using SQL Server.
- Examine sales, quantity, costs, and profitability.
- Build an interactive Power BI dashboard.
- Present business metrics and visualizations for data exploration.
- Document analysis, architecture, and validation activities.

## Tools and Technologies

- Microsoft SQL Server 2025
- SQL Server Management Studio (SSMS)
- Microsoft Power BI Desktop
- Power Query and DAX, where applicable
- AdventureWorksDW2025 sample dataset

## Dashboard Features

- Six KPI cards
- Five interactive slicers
- Monthly sales trend
- Sales by channel
- Total sales visualization
- Sales by country
- Top 10 products by sales

## Project Structure

- SQL Scripts/ — SQL analysis and validation queries
- Power BI/ — Power BI dashboard file
- Documentation/ — Project documentation
- Architecture/ — Data architecture diagram
- Test Results/ — Test cases and validation results
- Demo Recording/ — Project demonstration, planned
- Presentation/ — Project presentation, planned

## Data Source

AdventureWorksDW2025 sample data warehouse. Dashboard values depend on the data loaded, report filters, and measure definitions.

## Validation

SQL and Power BI results should be compared using matching filters and calculation definitions. Test statuses should reflect checks actually completed.

## Future Enhancements

- Publish the report to Power BI Service, if required
- Configure and validate scheduled refresh
- Enhance data modeling and report performance
- Add further analytical measures and visualizations

## Project Status

Power BI dashboard and core project documentation are in progress toward final validation and portfolio publication.
